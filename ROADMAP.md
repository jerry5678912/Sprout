# Roadmap

- Add package signatures, checksums, trust policy, and stronger extraction sandboxing.
- Improve dependency graph output and lockfile migration guarantees.
- Optimize VM dispatch, bytecode caching, and hot call paths.
- Add signed release artifacts and native application bundles.
- Add persistent on-disk workspace indexes and continue deepening control-flow
  analysis beyond the bounded in-memory 0.4 inference model.
- Add test debugging, coverage reporting, logpoints, data breakpoints, and broader semantic refactors.
- Add more cancellation checkpoints and parallel-safe isolated task runtimes.
- Grow the conformance corpus and add coverage-guided fuzzing in CI.
- Commission an external security review before operating a public registry.
- Extend gradual typing with overloads, protocols, richer generic inference,
  and deeper control-flow analysis.
